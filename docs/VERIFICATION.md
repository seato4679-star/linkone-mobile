## 修正して再確認した問題

1. 同一Origin判定で、Next.js内部のホスト名と127.0.0.1が一致しないケースを修正。外部Originは引き続き拒否。
2. Next.jsのストリーミングによるHTML内リダイレクトも、未認証ページのテストが正しく判定するよう修正。個人情報が含まれないことも確認。
3. モバイルの管理表で支援技術向け見出しがページを横にはみ出させた問題を修正。
4. 未入力送信時に最初のエラー入力へフォーカスを移すよう改善。
